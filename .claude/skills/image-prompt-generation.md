# Skill: Image Prompt Generation (for Gemini / Imagen)

Load when writing image-generation prompts for the Founder to run in Gemini
(Imagen). Owned by `media-prompt-director`. The goal: a prompt so specific the
Founder generates the RIGHT on-brand asset on the first or second try — no vague
"make it look good."

Full doctrine, checklists, and failure modes: `image-prompt-generation-reference.md`.
