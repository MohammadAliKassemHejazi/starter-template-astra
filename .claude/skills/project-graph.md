# Skill: Project Graph (Graphify — structural map of the codebase)

Load when a task needs to understand how the project fits together before
changing it: impact analysis before an edit, planning a refactor, finding what
consumes a module/route/type, spotting circular dependencies, onboarding to an
unfamiliar repo, or grooming a HIGH-tier change. Primary users: team-lead and
system-architect; any specialist may load it for blast-radius analysis.

Full doctrine, checklists, and failure modes: `project-graph-reference.md`.
