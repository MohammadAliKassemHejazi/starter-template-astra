# Skill: Extended Compliance (HIPAA / SOC 2 / CCPA / OSS Licensing)

Load when a client's market or data demands compliance beyond GDPR. Companion to
`gdpr-compliance.md` (which owns EU personal data + consent). We implement
technical controls and document evidence; the client's counsel/auditor owns the
legal determination — say so in every report. Compliance-triggering work is
security-sensitive → pairs with `security-auditor` + `security-audit.md`.

Full doctrine, checklists, and failure modes: `compliance-extended-reference.md`.
