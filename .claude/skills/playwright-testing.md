# Skill: Playwright E2E Verification (MCP)

Load when a UI change needs real-browser verification, or QA verifies a web story end-to-end.

**Requires**: Playwright MCP server (or local `@playwright/test`). If absent → fallback: local Playwright via `npx playwright test`; if neither, state that E2E was NOT run — never claim verification that didn't happen.

Full doctrine, checklists, and failure modes: `playwright-testing-reference.md`.
