# Skill: Video Prompt Generation (for Gemini / Veo)

Load when writing video-generation prompts for the Founder to run in Gemini
(Veo). Owned by `media-prompt-director`. Video needs everything an image prompt
has PLUS motion, time, and sequence — specified precisely so the generated clip
is usable (hero loop, product motion, social reel) on the first tries.

Full doctrine, checklists, and failure modes: `video-prompt-generation-reference.md`.
