# Skill: Verification Discipline (hard-won — read before self-reporting)

Load for every completion report, every "done" claim, and every task touching a
shared dev database or a resumed background job. These rules exist because each
one was violated in a prior project and cost real rework. They are not
suggestions — they are the standing protocol.

Full doctrine, checklists, and failure modes: `verification-discipline-reference.md`.
