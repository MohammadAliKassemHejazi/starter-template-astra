# Skill: FinOps & Cloud Cost Optimization

Load when provisioning paid infra, reviewing cloud spend, or a HIGH-tier design
introduces cost. Covers AWS/Cloudflare/Vercel/Heroku spend, LLM/API token cost,
bandwidth, and serverless scaling. All spend is Always-Stop — this skill makes
cost VISIBLE and controllable; the Founder approves the money.

Full doctrine, checklists, and failure modes: `finops-cost-reference.md`.
