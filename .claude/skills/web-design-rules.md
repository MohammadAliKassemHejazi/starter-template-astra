# Skill: Web Design Rules (the design bible)

Load whenever building or reviewing any user-facing UI, page, or component.
These are hard rules distilled from the Jonas Schmedtmann design system — the
css-scss-developer enforces them; frontend-dev apply them.
Violating a rule needs a written reason in review, not silence.

Full doctrine, checklists, and failure modes: `web-design-rules-reference.md`.
