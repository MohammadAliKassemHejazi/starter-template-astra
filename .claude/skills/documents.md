# Skill: Client Document Generation (docx / xlsx / pdf)

Load when a deliverable must be a real file the Founder forwards to a client: proposals, reports, pricing models, invoices, contracts, audits.

**Requires**: the official Anthropic document skills (docx, xlsx, pdf) available in the environment (Claude Code / claude.ai file creation). If absent → fallback: clean markdown + a note that conversion is pending.

Full doctrine, checklists, and failure modes: `documents-reference.md`.
