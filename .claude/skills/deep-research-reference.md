# Reference: deep-research

Deep detail for `deep-research.md`. Read this when actually implementing — not to decide whether the skill applies (the lean file + `skills/INDEX.md` answer that).

## Workflow
1. **Frame**: write the research question + 3–6 sub-questions FIRST; a search without a question list wanders.
2. **Search broad → narrow**: initial wide queries to map the landscape, then targeted queries per sub-question. Prioritize primary sources (official docs, filings, first-party data, papers) over aggregators and SEO listicles.
3. **Cross-verify**: any load-bearing claim needs 2+ independent sources; note where sources conflict instead of silently picking one.
4. **Date-stamp everything**: every finding carries its source date; flag anything older than 12 months in fast-moving spaces.
5. **Separate fact from inference**: findings sections quote/paraphrase sources; analysis sections are clearly the team's interpretation.

## Dossier format
Executive summary (answer the question in 5 lines) → key findings per sub-question (each with sources) → conflicting evidence → implications for THIS client (tied to `business-context.md`) → open questions → full source list with dates.

## Who uses it
**ceo**: market sizing, competitor moves, pricing benchmarks before advising the Founder. **content-marketing**: data-backed content, original-angle discovery. **team-lead**: technology/vendor evaluation for HIGH-tier grooming.

## Guardrails
No fabricated statistics, ever — a missing number is reported as missing. Paywalled content is summarized from abstracts/coverage, marked as such. Research involving a private individual (not a public figure) → decline and note why.
