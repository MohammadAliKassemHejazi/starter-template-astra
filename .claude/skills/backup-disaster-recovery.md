# Skill: Backup & Disaster Recovery

Load when setting up data protection or planning rollback/recovery. Ties to
`postgres-safety.md` (migrations) and `verification-discipline.md` (live-data
safety — the seed bug that wiped days of data is exactly what backups defend
against). Destructive recovery actions on live data are **Always-Stop**.

Full doctrine, checklists, and failure modes: `backup-disaster-recovery-reference.md`.
